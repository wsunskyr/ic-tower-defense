# 芯片保卫战 · IC Tower Defense

以 IC 设计为主题的网页塔防游戏（Phaser 3 + TypeScript + Vite），共 9 关。第 1 关只有放大器和振荡器，之后每关解锁一座新塔，地图和怪物也逐步变复杂。防御塔是电路模块，敌人是干扰芯片工作的噪声与失效机制。

## 运行

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 生产构建到 dist/
```

## 目录

| 路径 | 内容 |
|---|---|
| `src/config/levels.ts` | 9 个关卡：地图走线（支持多入口）、障碍物、配色、解锁的塔、起始能量、波次 |
| `src/config/towers.ts` | 防御塔数值（3 级），`info` 字段预留给以后的科普内容 |
| `src/config/enemies.ts` | 怪物数值与特性（减伤、闪避、隐身、成对、Boss） |
| `src/config/waves.ts` | 波次类型和清波奖励 |
| `src/config/map.ts` | 格子坐标、走线计算 |
| `src/scenes/` | `Boot`（加载）、`Menu`（选关）、`Game`（战斗） |
| `src/entities/` | `Tower`、`Enemy` |
| `src/audio.ts` | Web Audio 合成音效和背景音乐（选关 / 战斗 / Boss 三首循环曲） |
| `src/codex.ts` | 怪物图鉴：遇到过的怪物才显示详情 |
| `src/progress.ts` | 通关星数（浏览器 localStorage，键 `ic-td-progress-v2`） |
| `src/display.ts` | 高分辨率渲染：画布按设备像素比 2~3 倍绘制 |
| `src/dev/bot.ts` | 开发用的自动平衡测试，不进入生产包 |
| `public/assets/` | Q 版角色和元件障碍物 SVG，可直接替换美术 |

## 新增关卡

在 `src/config/levels.ts` 的 `LEVELS` 里加一项即可，`towers` 用 `upTo('塔')` 取解锁顺序里到该塔为止的列表，`unlock` 填本关新塔会在开局提示。走线用格子坐标（16×9），起点放在地图外一格，所有路径的终点必须是同一个格子（芯片）。

## 平衡测试

`npm run dev` 后在浏览器控制台运行：

```js
await __bot.run(3)   // "L3 won ❤8/10 towers=10 lives/wave=[...]"
```

这个策略不认识地图，只按覆盖走线最多的位置建塔（多条路径共用的走线权重更高），会优先试用本关新解锁的塔，水平大致相当于一个普通玩家。目前 1~9 关剩余生命约为 10/10/10/10/9/9/7/6/5。

## 机制速览

| 防御塔 | 效果 | 克制 |
|---|---|---|
| 放大器 | 单体直射 | 通用 |
| 振荡器 | 周期环形波，范围伤害，不会落空 | 热噪声群、抖动 |
| ADC | 血量低于斩杀线直接“量化”清除 | 1/f 噪声 |
| 滤波器 | 范围减速 + 少量持续伤害 | 毛刺 |
| 雷达 | 揭示隐身怪，范围内的怪受到更多伤害 | 电磁干扰 |
| 锁相环 | 锁定目标，伤害随锁定时间增加，不会落空 | 抖动、Boss |
| 混频器 | 命中后分出两路边带打向附近的怪 | 扎堆的怪群 |
| 比较器 | 专打血最多的怪；目标血量过半时判决为 1，暴击 | 1/f 噪声、Boss |
| LDO | 不攻击；给范围内的塔加攻速，并抵消静电瘫痪（满级免疫） | 静电放电 Boss |

解锁顺序：放大器、振荡器 → 滤波器 → ADC → 雷达 → 混频器 → 锁相环 → 比较器 → LDO。

快捷键：空格 开波 / 暂停，N 提前开下一波，F 切换 1x/2x/3x，P 或 Esc 打开暂停菜单（继续、重开、图鉴、音乐音效开关、返回选关）；切到别的标签页会自动暂停；建造菜单里 1~9 建塔，选中塔时 U 升级、S 出售。

提前开波：当前波的怪全部出场后，开始按钮变成「⏩ 提前」，立刻拿到本波的清波奖励，外加 15 + 场上怪数 × 3（最多 60）的提前奖励。

开发模式下 `window.__game` 暴露游戏实例，便于在控制台调试。
